# Инструкция по добавлению изображений

## Структура папок

```
images/
├── products/     # Изображения товаров
├── banners/      # Баннеры для главной страницы
└── icons/        # Иконки и логотипы
```

## Как добавить изображение к товару

### 1. Подготовьте изображение
- Формат: `.jpg`, `.png`, или `.webp` (рекомендуется)
- Размер: 800x1000 пикселей (соотношение 4:5)
- Вес: до 200 КБ для быстрой загрузки
- Имя файла: латиницей, без пробелов (например: `braslet-zhasmin-1.jpg`)

### 2. Положите файл в папку `products/`
Пример: `images/products/bra-jasmine-1.jpg`

### 3. Обновите данные товара

Есть два способа:

#### Способ А: Через админ-панель (рекомендуется)
1. Войдите в админку: `admin@example.com` / `admin123`
2. Перейдите в "Управление товарами"
3. Нажмите "Редактировать" у нужного товара
4. Укажите путь к изображению: `images/products/bra-jasmine-1.jpg`

#### Способ Б: Напрямую в localStorage
1. Откройте консоль браузера (F12)
2. Выполните команду:
```javascript
const products = JSON.parse(localStorage.getItem('products'));
products[0].images = ['images/products/bra-jasmine-1.jpg', 'images/products/bra-jasmine-2.jpg'];
localStorage.setItem('products', JSON.stringify(products));
location.reload();
```

## Форматы изображений

| Формат | Плюсы | Минусы | Когда использовать |
|--------|-------|--------|-------------------|
| **JPG** | Малый вес, хорошее качество | Нет прозрачности | Фото товаров, баннеры |
| **PNG** | Высокое качество, прозрачность | Большой вес | Логотипы, иконки |
| **WebP** | Отличное сжатие, современное | Не везде поддерживается | Основной формат для веба |

## Примеры путей к файлам

```html
<!-- Относительный путь (рекомендуется) -->
<img src="images/products/bra-jasmine-1.jpg" alt="Бюстгальтер Жасмин">

<!-- Абсолютный путь -->
<img src="/images/products/bra-jasmine-1.jpg" alt="Бюстгальтер Жасмин">
```

## Оптимизация изображений

Перед загрузкой сожмите изображения:
- Онлайн: [TinyPNG](https://tinypng.com/), [Squoosh](https://squoosh.app/)
- Программы: Adobe Photoshop, GIMP

## Плейсхолдеры

Пока реальные изображения не добавлены, используются автоматические SVG-плейсхолдеры с цветным фоном и текстом.

## Рекомендации

✅ Используйте одинаковый размер для всех фото товаров  
✅ Сжимайте изображения перед загрузкой  
✅ Добавляйте alt-текст для доступности  
✅ Используйте 2-3 фото с разных ракурсов  

❌ Не загружайте изображения больше 1 МБ  
❌ Не используйте кириллицу в именах файлов  
❌ Не растягивайте изображения с малым разрешением
